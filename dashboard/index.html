收藏率 = 藏 ÷ 赞。高于你的中位数（）说明大家收藏起来回看，而不只是点赞划过。 ★ = 爆款——互动达到你中位数的 3 倍以上，这些定义了你的风格。点任意分类标签可重新归类，改动保存在本浏览器。
说明：完播率 / 曝光量 / 播放量 不在这里——那些是「创作者中心」的私有数据，需要你本人登录，任何 API 都拿不到。

评审团

6位评委独立打分（1-10）。平均低于9触发修改。含一位「AI味过敏师」有一票否决权。评审的是下方选中的那篇草稿。

🔄 刷新我的数据

重新拉取你自己账号的全部笔记与互动数据，并重建仪表盘。

➕ 添加博主

粘贴博主的主页链接（小红书 App → 主页 → 分享 → 复制链接）或 24 位 ID，自动拉取 TA 的近期笔记并加入「小红书 创作者」列表。拉取后想生成 AI 深度分析，在 WorkBuddy 对话里说「分析新抓的博主」即可。

🔍 按关键词发现创作者

按赛道关键词搜索笔记、发现持续输出的创作者（按「关键词广度→互动量」排序），自动拉取头部博主的笔记。关键词用逗号分隔、不能含空格。约 $0.001/请求，一次发现几美分。

🔗 修复笔记链接

小红书对不带签名令牌的笔记链接会显示「当前笔记暂时无法浏览」。点这里为已抓取的笔记（你的全部 + 每位博主的前 5 篇）附加有效令牌，让链接正常跳转。令牌可能随时间失效，失效后再点一次即可。博主主页链接不受此影响，但需要浏览器已登录 xiaohongshu.com。
